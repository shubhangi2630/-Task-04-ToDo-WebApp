## To-Do Web Application

This project is a responsive and interactive To-Do Web App developed using HTML, CSS, and JavaScript.

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Set due date and time
- Search tasks instantly
- Displays Total, Completed, and Pending tasks
- Stores tasks using Local Storage
- Responsive design for desktop and mobile devices

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage API



## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Double-click `index.html` or open it in a browser.
4. Start adding and managing your tasks.

## Learning Outcomes

- DOM Manipulation
- Event Handling
- Local Storage
- Responsive Web Design
- CRUD Operations using JavaScript
